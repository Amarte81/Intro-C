Lezione 01 • Slide 1/4 Concetto Base

Come Pensa un Computer?

Un computer è una macchina incredibilmente veloce, ma non ha intelligenza propria: sa fare soltanto ciò che gli viene ordinato nei minimi dettagli.

I Due Elementi Fondamentali

  • Il Processore (CPU): è il "cervello" che esegue i calcoli uno dopo l'altro a velocità stratosferica.
  • La Memoria (RAM): è il "banco di lavoro" temporaneo dove sono salvati i dati e le istruzioni mentre il computer è acceso.
  • Il Linguaggio C: è un linguaggio che ci permette di spiegare alla macchina esattamente cosa fare, controllando sia i calcoli sia la memoria con la massima efficienza.

Perché Iniziare Proprio dal C?

Imparare il C significa capire come funzionano davvero le cose sotto il cofano. È la base su cui sono stati costruiti i moderni sistemi operativi (come Windows, Linux, macOS, Android), i videogiochi e i dispositivi intelligenti.

Qualunque altro linguaggio tu voglia imparare in futuro ti risulterà molto più intuitivo dopo aver compreso come il C dialoga con la macchina.

🚗 L'Analogia della Guida
Imparare il C è come imparare a guidare con il cambio manuale: all'inizio richiede attenzione, ma dopo sarai in grado di guidare qualunque veicolo con totale padronanza.

Le Variabili: Scatole per Ricordare i Dati

Un programma per fare calcoli deve poter memorizzare delle informazioni: l'età di una persona, il punteggio di un gioco, il prezzo di un prodotto.

📦 L'Analogia delle Scatole Etichettate
Pensa a una variabile come a una scatola nella memoria del computer. Ogni scatola ha:
1. Un'etichetta (il nome che scegli tu, es. eta o punteggio).
2. Un tipo (stabilisce cosa può contenere: numeri interi, con la virgola o lettere).
3. Un contenuto (il valore salvato dentro in quel momento, che può variare).

Numeri Interi: int

Per contare oggetti interi senza decimali (es. persone, monete, anni).

int eta = 25;
int vite = 3;

Numeri con Virgola: double

Per misurazioni precise e frazionarie (prezzi, temperature, altezze).

double prezzo = 19.99;
double temperatura = 36.5;

Singoli Caratteri: char

Per contenere una singola lettera, simbolo o cifra tra apici singoli ' '.

char iniziale = 'M';
char voto = 'A';

Vero o Falso (bool) e Come Nominare le Variabili

Molto spesso i computer devono ricordare risposte a domande del tipo: "La porta è aperta? L'utente ha pagato? Il gioco è terminato?".

Il Tipo Booleano: bool

Include la libreria <stdbool.h> per usare le parole chiare true (vero) e false (falso):

#include <stdbool.h>

bool gioco_attivo = true;
bool partita_vinta = false;

Per il computer internamente false vale 0 e true vale 1.

Regole d'Oro per i Nomi delle Variabili

  • Usa nomi chiari: preferisci punteggio a p, così chi legge il codice capisce subito a cosa serve.
  • I nomi possono contenere lettere, numeri e trattini bassi _ (es. giorni_lavorativi).
  • Non possono iniziare con un numero e non possono contenere spazi né accenti.
  • Il C è case sensitive: eta e Eta sono due scatole completamente diverse!

Lezione 03 • Slide 1/4 Aritmetica & Logica

Operatori: Ordinare al Computer di Fare Calcoli

Il computer eccelle nell'aritmetica. Possiamo combinare variabili e numeri con i simboli che già conosci dalla matematica.

I Calcoli Base

  • + Somma (es. 5 + 3 dà 8)
  • - Sottrazione (es. 10 - 4 dà 6)
  • * Moltiplicazione (es. 3 * 4 dà 12)
  • / Divisione (es. 10 / 2 dà 5)

Il Resto: Modulo %

L'operatore % calcola il resto della divisione tra numeri interi:

// 7 diviso 3 fa 2 con resto 1:
int resto = 7 % 3; // resto vale 1

// Trucco: se n % 2 è 0, 
// il numero è PARI!

Scorciatoie Comode

Aumentare o diminuire un contatore di 1 è un'operazione frequentissima:

int vite = 3;
vite++;  // vite diventa 4
vite--;  // vite torna a 3

vite += 5; // aggiunge 5 (vite = vite + 5)
📥 L'Operazione di Assegnazione (=) e le Assegnazioni Composte
In C, il simbolo = è l'operatore di assegnazione e agisce sempre da destra verso sinistra: variabile = valore; calcola l'espressione a destra e la ripone nella scatola a sinistra. Le forme come +=, -=, *= sono assegnazioni composte: ad esempio vite += 5; è la comoda scorciatoia per vite = vite + 5; (legge il valore attuale di vite, somma 5 e salva il nuovo risultato nella stessa variabile).

Lezione 03 • Slide 2/4 Input e Output

Dialogare con l'Utente: Scrivere e Leggere

Un programma interattivo deve poter mostrare messaggi sullo schermo e ascoltare ciò che l'utente digita dalla tastiera.

Esempio Completo di Input / Output
#include <stdio.h>

int main(void) {
    int anni;

    // 1. Chiediamo all'utente di scrivere
    printf("Quanti anni hai? ");

    // 2. Leggiamo il numero dalla tastiera
    scanf("%d", &anni);

    // 3. Mostriamo la risposta personalizzata
    printf("Hai %d anni! Nel 2030 ne avrai %d.\n", 
           anni, anni + 4);

    return 0;
}

I Simboli Segnaposto (%) e la & commerciale

  • %d: segnaposto per un numero intero (digit).
  • %.2f: segnaposto per un decimale (mostra 2 cifre dopo la virgola).
  • %c: segnaposto per un singolo carattere.
  • &nome_variabile: operatore di indirizzo obbligatorio con scanf per indicare la posizione esatta in memoria.
📬 Approfondimento: Perché la & commerciale in scanf?
Pensa alla & come al numero civico della scatola in memoria. Quando dici a scanf di salvare il dato digitato, devi dargli l'indirizzo esatto (&anni) dove andare fisicamente a posare quel valore!

Lezione 04 • Slide 1/4 Controllo del Flusso

Prendere Decisioni: Istruzioni Condizionali

Nella vita prendiamo continuamente decisioni: "SE piove prendo l'ombrello, ALTRIMENTI metto gli occhiali da sole". I programmi fanno esattamente la stessa cosa.

Il Comando if ed else

int eta = 16;

if (eta >= 18) {
    printf("Puoi prendere la patente auto!\n");
} else {
    printf("Devi ancora aspettare la maggiore età.\n");
}

Il blocco tra parentesi graffe { ... } viene eseguito solo se la condizione tra parentesi tonde risulta vera.

⚖️ Operatori di Confronto

  • == Uguale a: verifica se due valori sono identici (usa il doppio uguale per non confonderlo con l'assegnazione!).
  • != Diverso da: vero se i valori sono differenti.
  • > e >= Maggiore e Maggiore o uguale
  • < e <= Minore e Minore o uguale

🔗 Connettivi Logici

  • && AND (E contemporaneamente): entrambe le condizioni devono risultare vere (es. eta >= 18 && ha_patente).
  • || OR (OPPURE): basta che almeno una delle condizioni sia vera (es. giorno == 6 || giorno == 7).
  • ! NOT (Negazione logica): inverte la condizione, trasformando il vero in falso e viceversa (es. !piove).

✍️ L'Operazione di Assegnazione (=) e la Differenza con l'Uguaglianza (==)

Nel linguaggio C il simbolo = non indica un'uguaglianza matematica, ma è l'operazione di assegnazione: ordina al computer di memorizzare un nuovo valore dentro una variabile.

📥 Assegnazione: = (Un solo uguale)

È un'azione di scrittura (da destra verso sinistra). Calcola il valore a destra e lo versa nella scatola a sinistra: 

int punti = 10;     // Scrive 10 dentro 'punti'
punti = punti + 5;  // Ora 'punti' diventa 15
🔍 Confronto: == (Doppio uguale)

È una domanda di verifica. Non altera la variabile, chiede solo: "Il valore a sinistra è identico a quello a destra?": 

if (punti == 15) {  // Punti vale 15? Sì!
    printf("Hai vinto!\n");
}
⚠️ Attenzione al Trabocchetto Più Comune in C!
Se scrivi if (punti = 15) con un solo uguale, non stai controllando se punti vale 15: stai assegnando 15 a punti! Poiché 15 è diverso da 0, per il C il test risulterà sempre vero, producendo un errore logico invisibile. Ricorda la regola d'oro: un uguale assegna, due uguali confrontano!

Lezione 04 • Slide 2/4 Scelta Multipla

Scegliere tra Tante Opzioni: switch

Quando devi scegliere tra molte opzioni numeriche fisse (come un menu di un videogioco o i tasti di un ascensore), switch rende il codice ordinato e leggibile.

Menu con switch
int scelta = 2;

switch (scelta) {
    case 1:
        printf("Avvio Nuova Partita...\n");
        break; // Esce dal menu

    case 2:
        printf("Caricamento Salvataggio...\n");
        break;

    case 3:
        printf("Uscita dal gioco.\n");
        break;

    default:
        printf("Tasto non riconosciuto!\n");
        break;
}

Perché il comando break è Fondamentale?

Il comando break; ordina al computer: "Hai eseguito questo caso? Bene, adesso esci immediatamente dal menu!".

Se dimentichi il break;, il computer continuerà a eseguire a cascata anche le istruzioni del caso sottostante!

default: interviene se l'utente digita un numero che non corrisponde a nessuno dei casi previsti (come premere il tasto 9 in un ascensore di 4 piani).

Lezione 05 • Slide 1/5 Automazione & Ripetizione

Ripetere Senza Fatica: Il Ciclo while

Immagina di dover stampare i numeri da 1 a 1000. Scrivere 1000 righe a mano sarebbe noioso ed estenuante. I cicli automatizzano qualsiasi ripetizione.

Come Funziona il while ("Mentre...")

Il computer continua a eseguire le istruzioni all'infinito finché la condizione resta vera.

int conto_alla_rovescia = 5;

while (conto_alla_rovescia > 0) {
    printf("%d...\n", conto_alla_rovescia);
    conto_alla_rovescia--; // Toglie 1 ogni volta
}

printf("Partenza!\n");

🚨 Il Pericolo del Ciclo Infinito!

Se dimentichi di aggiornare la variabile (ad esempio togliendo conto_alla_rovescia--), la condizione rimarrà vera per sempre e il computer non uscirà mai dal ciclo, esaurendo risorse.

Assicurati sempre che all'interno del blocco tra graffe ci sia un'istruzione che avvicini la variabile al punto di arresto.

Lezione 05 • Slide 2/5 Esecuzione Garantita

Il Ciclo do-while: Eseguire Almeno Una Volta

A differenza del normale while che controlla prima di entrare, il do-while esegue sempre almeno una volta le istruzioni prima di verificare la condizione.

Esempio Tipico: Validazione dell'Input voto.c 
#include <stdio.h>

int main(void) {
    int voto;

    // Chiede il voto e RIPETE se non è valido:
    do {
        printf("Inserisci un voto da 1 a 10: ");
        scanf("%d", &voto);
    } while (voto < 1 || voto > 10); // <-- Punto e virgola obbligatorio!

    printf("Voto valido registrato: %d\n", voto);
    return 0;
}

💡 Prima si chiede il voto all'utente (azione iniziale), poi si controlla se è errato. Finché il voto non è tra 1 e 10, il ciclo richiede di digitare nuovamente il numero!

Confronto Diretto: while vs do-while

  • while (condizione):
    "Prima controlla, poi fai".
    Se la condizione è falsa fin dall'inizio, il corpo del ciclo non parte neanche una volta (0 esecuzioni).
  • do { ... } while (condizione);:
    "Prima fai, poi controlla".
    Le istruzioni tra graffe vengono eseguite almeno una volta, perché il test è posizionato alla fine.
  • ⚠️ La Regola del Punto e Virgola Finale:
    Nel do-while è obbligatorio inserire il punto e virgola ; subito dopo la parentesi tonda di chiusura: while (...);. Dimenticarlo è uno degli errori di distrazione più frequenti.
🏧 L'Analogia del PIN al Bancomat
Pensa all'inserimento del PIN allo sportello: devi obbligatoriamente digitare il codice la prima volta (azione do). Solo dopo averlo inserito, lo sportello controlla se è corretto (controllo while). Se hai sbagliato, ti richiede di digitarlo di nuovo finché non inserisci quello giusto!

Lezione 05 • Slide 3/5 Il Ciclo Perfetto

Il Ciclo for: Il Modo Più Comodo per Contare

Quando sai in anticipo quante volte ripetere un'azione (es. 10 volte, 100 volte), il ciclo for raggruppa tutto in una sola riga pulita ed elegante.

Anatomia del ciclo for
// 1. Parte da 0;  2. Finché i < 5;  3. Aumenta di 1
for (int i = 0; i < 5; i++) {
    printf("Giro numero: %d\n", i);
}

// Stampa sullo schermo:
// Giro numero: 0
// Giro numero: 1
// Giro numero: 2
// Giro numero: 3
// Giro numero: 4

I 3 Passi del for Spiegati

  1. Partenza (int i = 0): crea la variabile contatore i impostandola al valore iniziale.
  2. Traguardo (i < 5): prima di ogni giro controlla se non abbiamo ancora superato il limite.
  3. Passo (i++): al termine di ogni giro incrementa il contatore di 1.

La variabile i esiste solo dentro il ciclo: appena il ciclo finisce viene eliminata automaticamente per non creare confusione!

Le Funzioni: Costruire i Propri Strumenti

Un programma complesso può essere lungo migliaia di righe. Per non perdersi, si scompone il problema in "piccole macchine" riutilizzabili chiamate funzioni.

Esempio di Funzione: Calcolo Area Rettangolo
#include <stdio.h>

// 1. DEFINIAMO LA NOSTRA FUNZIONE
int calcola_area(int base, int altezza) {
    int risultato = base * altezza;
    return risultato; // Restituisce il valore calcolato
}

int main(void) {
    // 2. USIAMO LA FUNZIONE
    int a1 = calcola_area(5, 4);   // Restituisce 20
    int a2 = calcola_area(10, 3);  // Restituisce 30

    printf("Aree calcolate: %d e %d\n", a1, a2);
    return 0;
}

I 3 Componenti di una Funzione

  • Gli Ingressi (Parametri): sono i dati che diamo alla funzione (in questo caso la base e l'altezza).
  • Il Corpo: le istruzioni che lavorano su quei dati (la moltiplicazione).
  • L'Uscita (Valore di ritorno): la risposta che la funzione restituisce a chi l'ha chiamata (tramite la parola chiave return).
  • Se una funzione non deve restituire nulla (ad esempio deve solo stampare un saluto), si usa la parola speciale void (vuoto).

Lezione 06 • Slide 2/4 Regola Fondamentale

L'Analogia della Fotocopia (Passaggio per Valore)

Una delle regole più importanti del C: quando passi una variabile a una funzione, la funzione riceve una fotocopia, non l'originale!

📄 L'Analogia della Fotocopia
Se hai un foglio con i tuoi appunti a casa, ne fai una fotocopia e la consegni a un amico, e l'amico cancella o scrive qualcosa sulla fotocopia... il tuo foglio originale a casa rimane assolutamente intatto e invariato!

Cosa Succede nel Codice

void prova_modifica(int x) {
    x = 999; // Modifica solo la fotocopia locale!
}

int main(void) {
    int numero = 10;
    prova_modifica(numero);
    
    // 'numero' è rimasto 10!
    printf("%d", numero); 
    return 0;
}

E se Volessimo Modificare l'Originale?

Se vogliamo davvero che una funzione possa modificare il contenuto del nostro foglio originale a casa, non dobbiamo darle una fotocopia dei dati, ma l'indirizzo di casa della nostra scatola!

Questo è il magico potere dei Puntatori, che scopriremo nella Lezione 8!

Gli Array: Una Fila di Cassetti Numerati

Se devi registrare i voti di 30 studenti, non ha senso inventare 30 variabili diverse. Un array è una singola cassettiera con tanti cassetti ordinati.

Array di 5 Interi
// Crea una cassettiera con 5 scomparti

Perché in Informatica si Inizia a Contare da 0?

Questa è una delle curiosità che sorprende sempre i principianti! Il numero tra parentesi [ i ] non indica il numero d'ordine, ma la distanza (l'offset) dall'inizio:

  • Il 1° elemento è esattamente all'inizio → distanza 0.
  • Il 2° elemento è a distanza 1.
  • In un array da 5 posti, i cassetti sono numerati da 0 a 4.

Lezione 08 • Slide 1/4 Il Cuore del Computer

I Puntatori: I Numeri Civici della Memoria

Molti pensano che i puntatori siano difficili, ma in realtà il concetto è semplicissimo: un puntatore è solo un foglietto con scritto l'indirizzo di una scatola.

📬 L'Analogia della Casa e del Numero Civico
Pensa alla memoria del computer come a una lunghissima via con milioni di villette a schiera. Ciascuna villetta ha un numero civico unico (l'indirizzo di memoria). Una normale variabile è il mobile dentro casa; un puntatore è un biglietto da visita su cui hai scritto quel numero civico per ricordarti dove andare.

I Due Simboli Magici: & e *

  • &valore (Indirizzo di): legge il numero civico della scatola (es. 0x7FFE20).
  • *ptr (Vai a vedere dentro): segue l'indirizzo, apre la porta e ti permette di leggere o cambiare cosa c'è dentro.
int segreto = 42;

// ptr è un puntatore che memorizza l'indirizzo di 'segreto'
int *ptr = &segreto;

printf("Valore: %d\n", *ptr); // Stampa 42

// Modifichiamo il valore a distanza!
*ptr = 100;
printf("Nuovo: %d\n", segreto); // 'segreto' ora è 100!

Lezione 08 • Slide 2/4 Applicazione Pratica

Modificare Dati a Distanza: Lo Scambio (swap)

Ora capiamo finalmente perché i puntatori sono indispensabili: permettono a una funzione di andare a modificare le variabili originali.

La Funzione Scambia (swap)
// Riceve gli indirizzi di due scatole
void scambia(int *a, int *b) {
    int temporaneo = *a; // Legge valore in 'a'
    *a = *b;             // Mette valore di 'b' in 'a'
    *b = temporaneo;     // Mette il vecchio valore in 'b'
}

int main(void) {
    int x = 5, y = 10;
    
    // Passiamo gli indirizzi (&x, &y)
    scambia(&x, &y);
    
    // Ora x vale 10 e y vale 5!
    printf("x = %d, y = %d\n", x, y);
    return 0;
}

L'Analogia dei Due Bicchieri

Se hai un bicchiere con succo d'arancia e uno con succo di mela, per scambiarli ti serve un terzo bicchiere vuoto temporaneo:

  1. Versi l'arancia nel bicchiere temporaneo.
  2. Versi la mela nel primo bicchiere.
  3. Versi l'arancia dal temporaneo nel secondo bicchiere.

Grazie ai puntatori, la funzione ha potuto svolgere questo scambio direttamente sui bicchieri originali!

Lezione 09 • Slide 1/4 Dati Complessi

Le Strutture: Creare Schede di Dati Complete

Nel mondo reale gli oggetti hanno tante caratteristiche diverse. Ad esempio una persona ha un nome (testo), un'età (intero) e un'altezza (decimale). Con le struct possiamo raggrupparli insieme.

Definire una Scheda Studente
// Definiamo un nuovo tipo di dato chiamato 'Studente'
typedef struct {
    char nome[30];
    int matricola;
    double media_voti;
} Studente;

int main(void) {
    // Creiamo una nuova scheda studente
    Studente s1 = {"Mario Rossi", 102345, 28.5};

    // Si accede ai singoli campi con il punto (.)
    printf("Nome: %s, Media: %.1f\n", s1.nome, s1.media_voti);
    return 0;
}

L'Operatore Punto (.)

Il punto è la chiave per aprire un singolo scomparto della scheda:

  • s1.nome per leggere o scrivere il nome.
  • s1.matricola per il numero di matricola.
  • s1.media_voti per la media esami.

La parola typedef serve semplicemente per dare un nome breve e comodo (Studente) senza dover riscrivere ogni volta struct Studente.

Lezione 09 • Slide 2/4 Sintassi Pratica

L'Operatore Freccia (->)

Cosa succede se abbiamo un puntatore a una scheda? Il C ci regala una comoda scorciatoia visiva: la freccia ->.

Dalla Forma Lunga alla Freccia

Se ptr punta alla scheda s1, per accedere a un campo dovremmo scrivere: "apri la scatola puntata e prendi il campo", cioè (*ptr).media_voti.

Per evitare questa sintassi scomoda, in C si usa la freccia:

Studente s1 = {"Anna", 98765, 29.0};
Studente *ptr = &s1;

// Facile, intuitivo e chiaro:
ptr->matricola = 99999;
printf("Nuova matricola: %d\n", ptr->matricola);

Dare Nomi alle Opzioni: enum

Le enumerazioni (enum) permettono di sostituire numeri anonimi con etichette leggibili:

typedef enum {
    FERMO,       // Vale 0
    IN_MOVIMENTO,// Vale 1
    IN_PAUSA     // Vale 2
} StatoGioco;

StatoGioco stato = IN_MOVIMENTO;

Il codice diventa molto più chiaro da leggere rispetto a usare numeri a caso come 0 o 1.

Lezione 10 • Slide 1/5 La Memoria RAM

Il Banco di Lavoro (Stack) e il Magazzino (Heap)

Come organizza il computer la sua memoria durante l'esecuzione del programma? Ci sono due grandi aree da conoscere.

1. Lo Stack (Il Banco di Lavoro Rapido)

  • È lo spazio dove vengono create le normali variabili delle funzioni.
  • Completamente automatico: quando una funzione termina, tutte le sue variabili spariscono e la memoria si libera da sola.
  • È velocissimo, ma ha una capienza limitata (non puoi metterci array enormi da milioni di dati).

2. L'Heap (Il Grande Magazzino a Richiesta)

  • È un'area di memoria gigantesca (tutta la RAM disponibile nel computer).
  • Controllo manuale: sei tu che chiedi al computer una certa quantità di memoria quando ti serve, e decidi tu quando restituirla.
  • I dati rimangono vivi finché non decidi tu di eliminarli.
Lezione 10 • Slide 2/5 Memoria Dinamica

Chiedere Spazio: malloc e free

Grazie alla libreria <stdlib.h> possiamo chiedere spazio di memoria durante l'esecuzione del programma.

Il Ciclo di Vita della Memoria
#include <stdlib.h>

// 1. Chiediamo spazio per 100 numeri interi:
int *vettore = malloc(100 * sizeof(int));

// 2. Controlliamo che il computer avesse memoria libera
if (vettore == NULL) {
    printf("Memoria esaurita!\n");
    return 1;
}

// 3. Usiamo la memoria
vettore[0] = 42;

// 4. REGOLA D'ORO: RESTITUISCI LA MEMORIA!
free(vettore);
vettore = NULL; // Buona abitudine

Le Due Parole Chiave

  • malloc(dimensione): sta per Memory Allocation. Chiede al computer: "Per favore, riservami questi Byte nel magazzino" e ti restituisce l'indirizzo di memoria per raggiungerli.
  • free(puntatore): dice al computer: "Ho finito di usare questo spazio, rimettilo pure a disposizione per altri programmi".

Lezione 10 • Slide 4/5 Buone Abitudini

Buone Abitudini del Programmatore C

Consigli essenziali e regole d'oro per scrivere codice robusto, leggibile e privo di bug fin dal primo giorno.

I 4 Consigli per Non Sbagliare Mai

  • Inizializza sempre le variabili: una scatola appena creata contiene dati residui casuali; assegnale subito un valore iniziale (es. int conto = 0;).
  • Controlla gli indici degli array: non scrivere mai oltre la fine del cassetto per non corrompere la memoria.
  • Commenta il tuo codice: scrivi brevi commenti con // per spiegare a te stesso e agli altri cosa fa quella riga.
  • Fatti aiutare dal compilatore: attiva sempre gli avvisi con gcc -Wall -Wextra per farti segnalare subito eventuali distrazioni.

Leggibilità e Manutenzione del Codice

  • Indenta bene il codice: usa gli spazi o le tabulazioni dentro le graffe { ... } per evidenziare subito quali istruzioni appartengono a una funzione o a un blocco if/while.
  • Separa la logica in piccoli passi: se una funzione supera le 30-40 righe, valuta di dividerla in due funzioni più semplici e specializzate.
  • Gestisci sempre la memoria: ad ogni malloc associa sempre la sua free prima di uscire dal programma.
  • Non aver paura dei messaggi di errore: sono la guida migliore per correggere sviste e distrazioni di battitura!

Approfondimento Speciale • Memoria RAM Operatore sizeof

Approfondimento: L'Operatore sizeof

Come funziona la bilancia della memoria del C: sintassi, trucchi per calcolare la lunghezza degli array e il tipo speciale size_t.

1. Non è una Funzione: È a Costo Zero!

Anche se si usano le parentesi tonde come per le funzioni, sizeof è un operatore del compilatore.

Viene calcolato prima che il programma inizi, direttamente durante la compilazione: non consuma tempo di calcolo quando il programma è in esecuzione!

// Usato su un tipo:
printf("%zu\n", sizeof(int));    // Stampa 4
printf("%zu\n", sizeof(double)); // Stampa 8

2. Usato Direttamente sulle Variabili

Puoi passare a sizeof il nome di una variabile senza dover ricordare di quale tipo fosse:

double temperatura = 36.5;
int anni = 20;

// Le parentesi sono opzionali con le variabili:
printf("%zu byte\n", sizeof temperatura); // 8
printf("%zu byte\n", sizeof anni);        // 4

3. Il Trucco del Conteggio Array

Un trucco classico usato da tutti i programmatori C per contare quanti elementi ha un array senza contarli a mano:

int numeri[] = {10, 20, 30, 40, 50};

// Byte totali diviso byte del singolo elemento:
int lunghezza = sizeof(numeri) / sizeof(numeri[0]);
printf("Elementi: %d\n", lunghezza); // 5

4. Il Tipo di Ritorno: size_t e %zu

sizeof restituisce un tipo intero speciale chiamato size_t, garantito essere sufficientemente grande da contenere la dimensione massima di memoria del computer.

Per stamparlo con printf si usa il segnaposto specifico %zu:

printf("Spazio: %zu Byte\n", sizeof(int));
